# صندوق التكافل

نظام إدارة صندوق تكافلي بمساهمات طوعية مبني على Google Apps Script و Google Sheets.

## الوصف

نظام ويب لإدارة صندوق تكافلي (جمعية/مجلس) حيث يساهم كل عضو بأي مبلغ وفي أي وقت يناسبه - بدون دورات شهرية ثابتة وبدون مبلغ محدد. النظام يركز على:

- **المحاسبة الشفافة** - تتبع كامل لجميع المعاملات
- **سجل مراجعة كامل** - لا يتم حذف أي سجل، التصحيحات عبر تعديلات
- **السجلات غير قابلة للتعديل** - التصحيحات فقط عبر ورقة التعديلات
- **واجهة عربية كاملة** - جميع النصوص والرسائل بالعربية مع دعم RTL

## المميزات

- لوحة تحكم مع رصيد الصندوق والإحصائيات
- إدارة الأعضاء (إضافة، تعديل، إيقاف)
- تسجيل المساهمات (نقدي أو تحويل بنكي) بأي مبلغ وأي وقت
- تسجيل المصروفات مع الفئات
- تعديلات مالية (إضافة/خصم) مع ذكر السبب
- تسويات مالية للأعضاء
- تقارير مع تصدير إلى Excel و PDF
- سجل مراجعة كامل لجميع العمليات
- إدارة البنوك وفئات المصروفات

## المتطلبات

- حساب Google
- جدول بيانات Google Sheets

## التثبيت

### 1. إنشاء جدول البيانات

1. اذهب إلى [Google Sheets](https://sheets.google.com) وأنشئ جدول بيانات جديد
2. سمّه "صندوق التكافل"
3. انسخ معرف جدول البيانات من الرابط:
   ```
   https://docs.google.com/spreadsheets/d/[المعرف_هنا]/edit
   ```

### 2. إنشاء مشروع Apps Script

1. في جدول البيانات، اذهب إلى **الإضافات** ← **Apps Script**
2. احذف أي كود موجود

### 3. إضافة ملفات الباك إند

أنشئ الملفات التالية في محرر Apps Script وانسخ محتواها:

| الملف | الوصف |
|------|------|
| `Code.gs` | النقطة الرئيسية والتوجيه |
| `SchemaInit.gs` | تهيئة قاعدة البيانات |
| `Members.gs` | إدارة الأعضاء |
| `LedgerEngine.gs` | محرك الحسابات |
| `Transactions.gs` | المعاملات المالية |
| `Settings.gs` | الإعدادات والبنوك والفئات |
| `Rpc.gs` | مساعد الاستدعاء |

### 4. إضافة ملفات الواجهة

أنشئ ملفات HTML التالية:

| الملف | الوصف |
|------|------|
| `Index.html` | القالب الرئيسي |
| `App.html` | تطبيق JavaScript |
| `Styles.html` | أنماط CSS |

### 5. تحديث الإعدادات

في ملف `Code.gs`، عدّل `CONFIG.SPREADSHEET_ID` بمعرف جدول البيانات:

```javascript
const CONFIG = {
  SPREADSHEET_ID: 'معرف_جدول_البيانات_هنا',
  // ...
};
```

### 6. إعدادات المشروع

1. في Apps Script، اذهب إلى **إعدادات المشروع** (أيقونة الترس)
2. غيّر المنطقة الزمنية إلى `(GMT+03:00) Asia/Riyadh`

### 7. النشر

1. اضغط **نشر** ← **عملية نشر جديدة**
2. اختر النوع: **تطبيق ويب**
3. التنفيذ باسم: **أنا** (حسابك)
4. من يمكنه الوصول: **أنا فقط**
5. اضغط **نشر**
6. انسخ رابط التطبيق

### 8. التهيئة الأولى

1. افتح رابط التطبيق
2. اذهب إلى **الإعدادات**
3. اضغط **تهيئة / إصلاح النظام**
4. أضف البنوك وفئات المصروفات
