# مخطط قاعدة البيانات - صندوق التكافل

## نظرة عامة

قاعدة البيانات مبنية على Google Sheets وتتكون من 9 أوراق (جداول).

## الأوراق

### 1. Settings (الإعدادات)

| العمود | النوع | الوصف |
|--------|------|------|
| key | نص | مفتاح الإعداد |
| value | نص | قيمة الإعداد |
| updatedAt | تاريخ/وقت | تاريخ آخر تحديث |
| updatedBy | نص | البريد الإلكتروني للمحدث |

**الإعدادات الافتراضية:**
- `schemaVersion` - إصدار المخطط (1.0.0)
- `fundName` - اسم الصندوق
- `openingTreasuryCash` - الرصيد الافتتاحي
- `earliestAllowedDate` - أقدم تاريخ مسموح
- `currency` - العملة (ريال)

### 2. Members (الأعضاء)

| العمود | النوع | الوصف |
|--------|------|------|
| memberId | UUID | المعرف الفريد |
| displayName | نص | اسم العضو |
| joinDate | تاريخ | تاريخ الانضمام |
| status | نص | الحالة (نشط / غير نشط / مغلق) |
| phone | نص | رقم الهاتف |
| email | نص | البريد الإلكتروني |
| notes | نص | ملاحظات |
| createdAt | تاريخ/وقت | تاريخ الإنشاء |
| createdBy | نص | المنشئ |
| updatedAt | تاريخ/وقت | تاريخ التحديث |
| updatedBy | نص | المحدث |

**حالات العضو:**
- `نشط` - عضو فعال يشارك في الصندوق
- `غير نشط` - عضو توقف عن المشاركة (قد يكون له رصيد)
- `مغلق` - عضو تمت تسويته بالكامل

## المعادلات الحسابية

### رصيد العضو
```
صافي رصيد العضو = إجمالي المساهمات + التعديلات - التسويات
```

### رصيد الصندوق
```
رصيد الصندوق = الرصيد الافتتاحي
              + إجمالي المساهمات
              - مصروفات الصندوق
              + تعديلات الصندوق
              - التسويات
```

## القيود

- أسماء الأعضاء فريدة (لا تكرار)
- أسماء البنوك فريدة
- أسماء الفئات فريدة
- المبالغ يجب أن تكون أرقاماً موجبة (ما عدا التعديلات)
- التواريخ بتنسيق YYYY-MM-DD
- السجلات المالية لا تُعدل مباشرة (التصحيح عبر التعديلات)
